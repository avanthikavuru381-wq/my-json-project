# 🌍 AI Travel Guide Chatbot 🤖✈️

An intelligent AI-powered travel assistant that generates personalized travel plans based on user preferences like budget, duration, travel type, and food choices.

## 🚀 Features

* 🎙️ Voice input for destination search
* 🗺️ Interactive Google Maps integration
* 💰 Budget-based smart travel planning
* 🏨 Hotel suggestions with location links
* 🍽 Restaurant recommendations
* 📅 Day-wise itinerary generation
* 💬 Chat-based user interaction

## 🛠️ Tech Stack

* Python
* Streamlit
* Groq API (LLM - LLaMA 3)
* HTML/CSS (for UI styling)

## ⚙️ How It Works

1. User enters travel details (origin, destination, budget, etc.)
2. Voice input option captures destination using speech-to-text
3. AI model generates a personalized travel plan
4. Google Maps links are dynamically added for locations
5. Interactive map is displayed for better visualization

## 📸 Output

Generates a complete travel guide including:

* Route overview
* Best time to visit
* Day-wise itinerary
* Top attractions
* Hotels & restaurants
* Budget estimation
